    3.1. 使用 Visual Studio.net 在 XP 家庭版上构建 Web 项目

    要构建 Web 应用程序项目，通常选择 [Application Web ASP.NET] 类型。此类项目需要本地或远程的 IIS Web 服务器。 若在 Windows 系统上工作，该服务器并不存在且无法安装。因此无法创建 XP 类型的项目。

    创建以下 Visual Studio 项目：

    被测试的类位于 [Personne.vb] 中：

    Public Class Personne

     ' 私有字段
    Private _nom As String
    Private _age As Integer

     ' 默认构造函数
    Public Sub New()
    End Sub

     ' 与私有字段关联的属性
    Public Property nom() As String
        Get
            Return _nom
        End Get
        Set(ByVal Value As String)
            _nom = Value
        End Set
    End Property

    Public Property age() As Integer
        Get
            Return _age
        End Get
        Set(ByVal Value As Integer)
            _age = Value
        End Set
    End Property

     ' 标识符字符串
    Public Overrides Function tostring() As String
        Return String.Format("[{0},{1}]", nom, age)
    End Function

     ' init 方法
    Public Sub init()
        Console.WriteLine("init personne {0}", Me.ToString)
    End Sub

     ' close 方法
    Public Sub close()
        Console.WriteLine("destroy personne {0}", Me.ToString)
    End Sub

End Class

    测试类位于 [NunitTestPersonne-1.vb] 中：

    Imports System
Imports NUnit.Framework

<TestFixture()> _
 Public Class NunitTestPersonne

     ' 被测试对象
    Private personne1 As Personne

    <SetUp()> _
    Public Sub init()
         ' 创建 Personne 实例
        personne1 = New Personne
         ' 日志
        Console.WriteLine("setup test")
    End Sub

    <Test()> _
    Public Sub demo()
         ' 屏幕日志
        Console.WriteLine("début test")
         ' 初始化person1
        With personne1
            .nom = "paul"
            .age = 10
        End With
         ' 测试
        Assert.AreEqual("paul", personne1.nom)
        Assert.AreEqual(10, personne1.age)
         ' 屏幕日志
        Console.WriteLine("fin test")
    End Sub

    <TearDown()> _
    Public Sub destroy()
         ' 跟踪
        Console.WriteLine("teardown test")
    End Sub

End Class

    有几点需要注意：

    • 方法带有诸如 <Setup()>、<TearDown()> 等属性
    • 要使这些属性被识别，必须满足以下条件：
      • 项目必须引用 [nunit.framework.dll] 程序集
      • 测试类导入命名空间 [NUnit.Framework]

    在解决方案资源管理器中右键单击 [References] 即可添加引用：

    如果 [Nunit] 的安装成功，则 [nunit.framework.dll] 应出现在所提供的列表中。只需双击该程序集即可将其添加到项目中：

    完成上述操作后，测试类 [NunitTestPersonne] 必须导入命名空间 [NUnit.Framework]：

    Imports NUnit.Framework

    此时，测试类 [NunitTestPersonne] 的属性应被识别。

    • <Test()> 属性指定要测试的方法
    • <Setup()> 属性表示在每个被测方法之前执行的方法
    • <TearDown()> 属性表示在每次测试方法之后要执行的方法
    • 方法 Assert.AreEqual 用于测试两个 entités.Il 是否相等，此外还有许多其他 Assert.xx 类型的方法。
    • 实用程序 NUnit 会在任何 [Assert] 方法失败时立即停止被测试方法的执行并显示错误信息。否则，它将显示成功信息。

    • 连接字符串 [ConnectString] 是一个值得了解的属性，因为代码 .NET 需要它来建立与数据库的连接。此处的连接字符串为： 
    Provider=SQLOLEDB.1;Persist Security Info=False;User ID=admarticles;Initial Catalog=dbarticles;Data Source=portable1_tahe\msde140405;Use Procedure for Prepare=1;Auto Translate=True;Packet Size=4096;Workstation ID=PORTABLE1_TAHE;Use Encryption for Data=False;Tag with column collation when possible=False

    该连接字符串中的许多元素都有默认值。我们可以直接使用以下连接字符串：

    "Provider=SQLOLEDB.1;Persist Security Info=False;User ID=admarticles;Initial Catalog=dbarticles;Data Source=portable1_tahe\msde140405;PASSWORD=mdparticles"
