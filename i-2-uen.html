    2.2. webarticles 应用程序 - 回顾

    本文将介绍第 1 部分中研究的简化电子商务 Web 应用程序的组成部分。该应用程序允许 Web 用户：

    2.2.2. 应用程序的总体架构

    第 1 部分构建的应用程序采用三层架构：

    • 通过使用接口，使这三层相互独立
    • 各层之间的集成通过Spring实现
    • 每层均采用独立的命名空间：web（Web层）、domain（业务层）和dao（数据访问层）。

    该应用程序遵循MVC（模型-视图-控制器）架构。若参照上文的分层图，MVC架构的整合方式如下：

    客户端请求的处理流程如下：

    1. 客户端向控制器发送请求。此处的控制器是一个承担特殊角色的 .aspx 页面。它处理所有客户端的请求，是应用程序的入口，即 MVC 架构中的“C”。
    2. 控制器处理该请求。为此，它可能需要业务层的协助，即MVC架构中的M模型。
    3. 控制器从业务层收到响应。客户端的请求已得到处理。这可能导致多种可能的响应。一个典型的例子是
      • 如果请求无法正确处理，则显示错误页面
      • 否则则返回确认页面
    4. 控制器选择要发送给客户端的响应（即视图）。该响应通常是一个包含动态元素的页面。控制器将这些元素提供给视图。
    5. 视图被发送给客户端。这就是MVC中的“V”。

    2.2.5. [dao] 层的重新审视

    在我们对 [dao] 层的首个实现中，数据访问接口 [IArticlesDao] 通过一个将文章存储在 [ArrayList] 对象中的类来实现。 这使我们无需过多关注该层，并证明了只有其接口才是关键，而非具体实现。由此，我们成功构建了一个可运行的Web应用程序。该应用程序包含三个层：[web]、[domain]和[dao]。 本文将提供 [dao] 层的不同实现方案。 每种实现方案均可替代当前的 [dao] 层，且无需对 [domain] 和 [web] 层进行任何修改。之所以能实现这种灵活性，是因为：

    • [domain] 层不是针对具体类，而是针对 [IArticlesDao] 接口
    • 借助 Spring，我们能够向 [domain] 层隐藏 [IArticlesDao] 接口的实现类名称。

    2.2.5.2. [Article] 类

    定义文章的类如下：

    Imports System

Namespace istia.st.articles.dao

    Public Class Article

         ' 私有字段
        Private _id As Integer
        Private _nom As String
        Private _prix As Double
        Private _stockactuel As Integer
        Private _stockminimum As Integer

         ' 商品编号
        Public Property id() As Integer
            Get
                Return _id
            End Get
            Set(ByVal Value As Integer)
                If Value <= 0 Then
                    Throw New Exception("Le champ id [" + Value.ToString + "] est invalide")
                End If
                Me._id = Value
            End Set
        End Property

         ' 商品名称
        Public Property nom() As String
            Get
                Return _nom
            End Get
            Set(ByVal Value As String)
                If Value Is Nothing OrElse Value.Trim.Equals("") Then
                    Throw New Exception("Le champ nom [" + Value + "] est invalide")
                End If
                Me._nom = Value
            End Set
        End Property

         ' 商品价格
        Public Property prix() As Double
            Get
                Return _prix
            End Get
            Set(ByVal Value As Double)
                If Value < 0 Then
                    Throw New Exception("Le champ prix [" + Value.ToString + "] est invalide")
                End If
                Me._prix = Value
            End Set
        End Property

         ' 当前库存
        Public Property stockactuel() As Integer
            Get
                Return _stockactuel
            End Get
            Set(ByVal Value As Integer)
                If Value < 0 Then
                    Throw New Exception("Le champ stockActuel [" + Value.ToString + "] est invalide")
                End If
                Me._stockactuel = Value
            End Set
        End Property

         ' 商品最低库存
        Public Property stockminimum() As Integer
            Get
                Return _stockminimum
            End Get
            Set(ByVal Value As Integer)
                If Value < 0 Then
                    Throw New Exception("Le champ stockMinimum [" + Value.ToString + "] est invalide")
                End If
                Me._stockminimum = Value
            End Set
        End Property

         ' 默认制造商
        Public Sub New()
        End Sub

         ' 带属性的制造商
        Public Sub New(ByVal id As Integer, ByVal nom As String, ByVal prix As Double, ByVal stockactuel As Integer, ByVal stockminimum As Integer)
            Me.id = id
            Me.nom = nom
            Me.prix = prix
            Me.stockactuel = stockactuel
            Me.stockminimum = stockminimum
        End Sub

         ' 商品识别方法
        Public Overrides Function ToString() As String
            Return "[" + id.ToString + "," + nom + "," + prix.ToString + "," + stockactuel.ToString + "," + stockminimum.ToString + "]"
        End Function
    End Class
End Namespace

    1. 一个构造函数，用于设置文章的5项信息：[id, nom, prix, stockactuel, stockminimum]

    3. 对插入到商品中的数据进行验证。若数据有误，将抛出异常。
    4. 方法 toString，用于获取商品的字符串值。这在应用程序调试中通常非常有用。

            Private Function executeQuery(ByVal query As OdbcCommand) As IList
             ' 执行查询SELECT 
             ' 声明允许访问结果表所有行的对象
            Dim myReader As OdbcDataReader = Nothing
            Try
                 '建立连接至 BDD
                connexion.Open()
                 '执行查询
                myReader = query.ExecuteReader()
                 '声明一个项目列表以便后续返回
                Dim articles As IList = New ArrayList
                Dim unArticle As Article
                While myReader.Read()
                     '根据读取器的值准备一个商品
                    unArticle = New Article
                    unArticle.id = myReader.GetInt32(0)
                    unArticle.nom = myReader.GetString(1)
                    unArticle.prix = myReader.GetDouble(2)
                    unArticle.stockactuel = myReader.GetInt32(3)
                    unArticle.stockminimum = myReader.GetInt32(4)
                     '将商品添加到列表中
                    articles.Add(unArticle)
                End While
                 '返回结果
                Return articles
            Finally
                 '释放资源
                If Not myReader Is Nothing And Not myReader.IsClosed Then myReader.Close()
                If Not connexion Is Nothing Then connexion.Close()
            End Try
        End Function

                connexion.Open()

                myReader = query.ExecuteReader()
                 '声明一个项目列表以便后续返回
                Dim articles As IList = New ArrayList
                Dim unArticle As Article
                While myReader.Read()
                     '根据读取器的值准备一个商品

                    unArticle.id = myReader.GetInt32(0)
                    unArticle.nom = myReader.GetString(1)
                    unArticle.prix = myReader.GetDouble(2)
                    unArticle.stockactuel = myReader.GetInt32(3)
                    unArticle.stockminimum = myReader.GetInt32(4)
                     '将商品添加到列表中
                    articles.Add(unArticle)
                End While
                 '返回结果
                Return articles
            Finally
                 '释放资源
                If Not myReader Is Nothing And Not myReader.IsClosed Then myReader.Close()
                If Not connexion Is Nothing Then connexion.Close()
            End Try
        End Function

                 '正在执行查询

            Finally
                 ' 释放资源
                If Not connexion Is Nothing Then connexion.Close()
            End Try

        Private Function executeQuery(ByVal query As OleDbCommand) As IList
             ' 执行查询 SELECT 
             ' 声明对象以访问结果表中的所有行
            Dim myReader As OleDbDataReader = Nothing
            Try
                 '建立连接至 BDD
                connexion.Open()
                 '执行查询
                myReader = query.ExecuteReader()
                 '声明一个项目列表以便后续返回
                Dim articles As IList = New ArrayList
                Dim unArticle As Article
                While myReader.Read()
                     '根据读取器的值准备一个商品
                    unArticle = New Article
                    unArticle.id = myReader.GetInt32(0)
                    unArticle.nom = myReader.GetString(1)
                    unArticle.prix = myReader.GetDouble(2)
                    unArticle.stockactuel = myReader.GetInt32(3)
                    unArticle.stockminimum = myReader.GetInt32(4)
                     '将商品添加到列表中
                    articles.Add(unArticle)
                End While
                 '返回结果
                Return articles
            Finally
                 '释放资源
                If Not myReader Is Nothing And Not myReader.IsClosed Then myReader.Close()
                If Not connexion Is Nothing Then connexion.Close()
            End Try
        End Function

        Private Function executeUpdate(ByVal sqlCommand As OleDbCommand) As Integer
             ' 执行更新请求
            Try
                 '建立与 BDD 的连接
                connexion.Open()
                 '正在执行查询
                Return sqlCommand.ExecuteNonQuery()
            Finally
                 ' 释放资源
                If Not connexion Is Nothing Then connexion.Close()
            End Try
        End Function

        Private Function executeQuery(ByVal query As FbCommand) As IList
             ' 执行查询 SELECT 
             ' 声明对象以访问结果表中的所有行

                 '建立连接至 BDD
                connexion.Open()
                 '执行查询
                myReader = query.ExecuteReader()
                 '声明商品列表以便后续返回

                Dim unArticle As Article
                While myReader.Read()
                     '正在根据阅读器的数值准备一篇文章

                    unArticle.id = myReader.GetInt32(0)
                    unArticle.nom = myReader.GetString(1)

                    unArticle.stockactuel = myReader.GetInt32(3)
                    unArticle.stockminimum = myReader.GetInt32(4)
                     '将文章添加到列表中
                    articles.Add(unArticle)
                End While
                 '返回结果
                Return articles
            Finally
                 ' 释放资源
                If Not myReader Is Nothing And Not myReader.IsClosed Then myReader.Close()
                If Not connexion Is Nothing Then connexion.Close()
            End Try
        End Function

             ' 执行更新请求

                 '建立与 BDD 的连接
                connexion.Open()
                 '执行查询
                Return updateCommand.ExecuteNonQuery()
            Finally
                 ' 释放资源
                If Not connexion Is Nothing Then connexion.Close()
            End Try
        End Function

    2.5.6.1. Ibatis 产品 SqlMap

    我们为应用程序 [webarticles] 的 [dao] 层编写了四种不同的实现。 每次我们都能将新的 [dao] 层集成到 [webarticles] 应用程序中，而无需重新编译另外两个层 [web] 和 [domain]。 需要重申的是，这一成果得益于两项架构设计：

    • 通过接口访问各层
    • 通过 Spring 集成各层

    我们希望更进一步。尽管各不相同，但我们对 [dao] 层的四种实现却有着惊人的相似之处。一旦写好了第一个实现，其余三个几乎就是通过复制粘贴并替换某些关键字而得出的。 而业务逻辑则未作任何修改。这不禁让人思考：是否有可能设计一种实现方案，让我们摆脱对不同数据访问模式的依赖？我们目前使用了四种方式：

    • 通过驱动程序 ODBC 访问数据源 ODBC
    • 直接访问 SQL Server 数据库
    • 通过 Ole Db 驱动程序访问 Ole Db 数据源
    • 直接访问 Firebird 数据库

    Ibatis SqlMap [[http://www.ibatis.com/] 工具使得能够开发与数据源实际类型无关的数据访问层。数据访问通过以下方式实现：

    • 配置文件，其中包含定义数据源及所需操作的信息
    • 基于这些信息访问数据的类库

    Ibatis SqlMap 工具最初是为 Java 平台开发的。其移植到 .NET 平台的时间较短，且似乎存在部分缺陷（此为个人观点，尚需深入验证）。 尽管如此，鉴于该工具在Java平台上已得到充分验证，介绍其.NET版本仍具有参考价值。

    • 文件 [sqlmap.config] 主要定义了连接包含数据的数据库的连接字符串。 通过实例化在 [providers.config] 中定义的 [Connection] 类来建立数据库连接，并将 [sqlmap.config] 中定义的连接字符串传递给该类的构造函数。

      • 数据表行与类之间的关联.NET，其实例将包含这些行
      • 需执行的 SQL 操作。这些操作通过名称进行标识。 代码 .NET 通过名称执行这些操作，从而消除了代码 .NET 中所有 SQL 代码。

    SqlMap 的类包含在 DLL 中，该文件通常放置在应用程序的 [bin] 文件夹中：

    使用 SqlMap 类库的应用程序必须导入 [IBatisNet.DataMapper] 命名空间：

    Imports IBatisNet.DataMapper

    所有 SQL 操作均通过 [Mapper] 类型的单例实现，该类属于 [IBatisNet.DataMapper ] 命名空间。单例的获取方式如下：

            Dim mappeur As SqlMapper = Mapper.Instance

    要执行命令 SqlMap [getAllArticles]，应编写如下代码：

                        dim articles as IList=mappeur.QueryForList("getAllArticles", Nothing)
    • 方法 [QueryForList] 可将命令 SELECT 的结果以列表形式输出
    • 第一个参数是要执行的命令 SQL 的名称（参见 articles.xml）
    • 第二个参数是要传递给 SQL 请求的参数。必须与 SqlMap 命令的 [parameterClass] 属性相对应。 在 [articles.xml] 中，我们有 [parameterClass=Nothing]。因此，此处传递一个空指针。
    • 结果类型为 IList。该列表中的对象由 SQL-select 命令的 [resultMap] 属性指定：[resultMap="article"]。“article”是一个映射名称： 
    <resultMap id="article" class="istia.st.articles.dao.Article">

    与该映射关联的类是 [istia.st.articles.dao.Article]。最终，前面定义的变量 [articles] 是一个由 [ istia.st.articles.dao.Article] 对象组成的列表。 因此，我们仅用一条语句就获取了整个 [ARTICLES] 表。如果 [ARTICLES] 表为空，则会得到一个包含 0 个元素的 [IList] 对象。

    要执行命令 SqlMap [getArticleById]，应编写如下代码：

    dim unArticle as Article=CType(mappeur.QueryForObject("getArticleById", idArticle), Article)
    • 方法 [QueryForObject] 可获取仅返回一行结果的命令 SELECT 的结果
    • 第一个参数是要执行的命令名称 SqlMap
    • 第二个参数是要传递给 SQL 请求的参数。必须与命令 SqlMap 的 [parameterClass] 属性相对应。 在 [articles.xml] 中，我们有 [parameterClass="int"]。因此，这里传递一个整数，代表要查找的商品编号。
    • 结果类型为 Object。如果 SELECT 未返回任何行，则结果为空指针（nothing）。

    要执行命令 SqlMap [insertArticle]，应编写如下代码：

                        mappeur.Insert("insertArticle", unArticle)
    • 方法 [Insert] 用于执行命令 SQL INSERT
    • 第一个参数是要执行的命令名称 SqlMap
    • 第二个参数是要传递给该命令的参数。必须与命令 SqlMap 的 [parameterClass] 属性相对应。 在 [articles.xml] 中，我们有 [parameterClass="istia.st.articles.dao.Article"]。因此，这里传递的是类型为 [istia.st.articles.dao.Article] 的对象。

    要执行命令 SqlMap [deleteArticle]，应编写如下代码：

                        dim nbArticles as Integer=mappeur.Delete("deleteArticle", idArticle)
    • 方法 [Delete] 允许执行命令 SQL DELETE
    • 第一个参数是要执行的命令名称 SQL
    • 第二个参数是要传递给该命令的参数。必须与命令 SqlMap 的 [parameterClass] 属性相对应。 在 [articles.xml] 中，我们有 [parameterClass="int"]。因此，这里传递的是要删除的商品编号。
    • 方法 [Delete] 的结果是已删除的行数

    同理，要执行命令 SqlMap [clearAllArticles]，应输入：

                        dim nbArticles as Integer=mappeur.Delete("clearAllArticles", nothing)

    要执行命令 SqlMap [modifyArticle]，应输入：

                        dim nbArticles as Integer=mappeur.Update("modifyArticle", unArticle)
    • 方法 [Update] 用于执行命令 SQL UPDATE
    • 第一个参数是要执行的命令名称 SqlMap
    • 第二个参数是要传递给该命令的参数。必须与命令 SqlMap 的 [parameterClass] 属性相对应。 在 [articles.xml] 中，我们有 [parameterClass="istia.st.articles.dao.Article"]。因此，这里传递的是类型为 [istia.st.articles.dao.Article] 的对象。
    • 方法 [Update] 的返回结果是修改的行数。

    2.5.7. 结论

    至此，这篇长篇教程文章告一段落。我们做了什么？

    • 我们通过四种不同方式实现了三层Web应用程序中[dao]层：
      1. 使用访问类 .NET 访问源代码 ODBC
      2. 使用访问类 .NET 访问源代码 SQL Server

      4. 使用第三方访问类访问 Firebird 数据库
    • 每次，我们都将新的 [dao] 层集成到三层应用程序 [webarticles] 中，而无需重新编译 [web, domain, dao] 或 [web, domain] 中的任何层
    • 最后，我们推出了工具 [SqlMap]，它使我们能够创建一个 [dao] 层，该层能够以对代码透明的方式适配不同的数据源。因此，借助这个新层，我们得以依次使用之前 1 到 3 号实现中的数据源。 这一过程是通过配置文件以透明的方式实现的。
