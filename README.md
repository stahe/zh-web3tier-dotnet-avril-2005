## 简介

本文档介绍了如何使用 **VB.NET**、**ASP.NET** 和 **Spring.NET** 开发 **三层 Web 应用程序**。  

其目的是演示如何通过明确划分以下部分来构建应用程序：
- 用户界面
- 业务逻辑
- 数据访问
本教程将利用 **Spring.NET** 框架，基于 **IoC（控制反转）** 原则对应用程序组件进行配置和组装。

这种方法特别允许在不影响应用程序其他部分的情况下，修改某个层的实现。 

---

## 教程目标

本文的主要目标包括：

- 编写一个**三层Web应用程序**：
  - 用户界面层
  - 业务层
  - 数据访问层
- 使用**Spring IoC**配置应用程序
- 通过修改一个或多个层的实现来生成**应用程序的多个版本**，以展示该架构的灵活性。
